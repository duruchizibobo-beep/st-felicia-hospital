# St Felicia Medical Specialists Hospital Website

A modern, responsive, zero-cost static hospital website with a browser-based Care Assistant.

## Included
- Responsive professional hospital landing page
- Obstetric and gynaecologic service sections
- Specialist section
- Contact/location section
- Appointment request form
- Browser `mailto:` appointment workflow — no paid backend required
- Local rule-based Care Assistant — no API key or external AI service required
- Emergency safety messaging
- Mobile navigation
- Google Maps search link

## Run locally
Simply open `index.html` in a browser.

For a local development server, if Python is installed:
`python -m http.server 5500`

Then visit:
`http://localhost:5500`
